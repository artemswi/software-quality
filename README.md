# Customs System (Митниця)

**Customs System** — це сучасний додаток, розроблений на Java, для автоматизації роботи митних органів. Програма дозволяє працювати з митними деклараціями, управляти базами даних, здійснювати огляд товарів, налаштовувати тарифи та керувати персоналом.

---

## Основні можливості:
- **Аутентифікація користувачів:**
    - Підтримка ролей: Адміністратор, Брокер, Інспектор.
    - Вхід у систему на основі логіна й пароля.

- **Управління митними деклараціями:**
    - Перегляд, створення та редагування декларацій.
    - Оновлення статусу на "В очікуванні", "Оброблено", "Відхилено".

- **Інтегровані бази даних:**
    - Тарифи за країнами, категоріями та напрямками.
    - Управління списками працівників та їхніми графіками.

- **Огляд товарів:**
    - Додавання звітів про перевірку товарів із записами в базу (`оглядтовара`).

- **Інтерфейс користувача (UI):**
    - Інтуїтивний графічний інтерфейс для кожної ролі:
        - **Адміністратор:** Керує користувачами, працівниками та тарифами.
        - **Брокер:** Подає декларації.
        - **Інспектор:** Проводить огляди товарів.

---

## Системні вимоги:
- **Мова програмування:** Java SDK 21.
- **База даних:** MySQL Server 8.0 або новіша.
- **Інструменти розробки:** IntelliJ IDEA.
- **Система:** Windows.

---

## Як запустити проєкт:
1. **Склонуйте репозиторій:**
   ```bash
   git clone https://github.com/your-username/customs-system.git
   cd customs-system
   ```

2. **Підготуйте базу даних:**
    - Відредагуйте файл `db_config.properties.example`, щоб вказати свої параметри з'єднання:
      ```
      db.url=jdbc:mysql://localhost:3306/my_database
      db.user=my_user
      db.password=my_password
      ```
    - Перейменуйте файл у `db_config.properties` і помістіть у папку `src/db/`.

    - Створіть структуру бази даних, використовуючи SQL-скрипт:
      ```bash
      db/schema.sql
      ```

3. **Запустіть проєкт:**
    - Відкрийте проєкт у IntelliJ IDEA.
    - Виконайте або запустіть основний клас `Main.java`.
